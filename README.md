# Car Wash Cashier System

A simple car wash cashier system built using Python.

## Description
This project is a simple cashier application
developed as part of an Algorithm and Programming
practicum assignment.

## Features
- Check car wash operating hours.
- Select car wash packages (VIP, Standard, and Kilat).
- Add tire polishing services.
- Calculate total payment.
- Display payment receipts.

## Technologies
- Python 3
- Conditional Statements (if, elif, else)
- User Input
- Basic Arithmetic Operations
